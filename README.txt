# CMoney 面試旅程（純 JS 版）

這個資料夾包含：
- `index.html`：載入 React 18（Production）與 Tailwind CDN，並掛載 App。
- `interview_journey.js`：由 JSX 轉為 `React.createElement` 的純 JavaScript，可直接在瀏覽器執行。
- `vercel.json`：（可選）啟用乾淨網址設定。

## 本機預覽
直接用任何靜態伺服器（或直接雙擊 index.html 亦可）

## 部署到 Vercel
- 推到 GitHub 後，在 Vercel 新增專案即可（Framework 選擇 Static）。
